# ⚽ Ronaldo Website

Мой первый сайт — фан-страница о Криштиану Роналду. Сначала сделан на чистом HTML, потом переделан с адаптивной вёрсткой.

🔗 **Демо:** https://feelweakk.github.io/ronaldo-website

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## Что внутри

- Две страницы: главная и карьера
- Адаптивная вёрстка: CSS Grid и медиазапросы, нормально выглядит на телефоне
- Цвета в CSS-переменных
- Таймлайн клубов и карточки достижений

## Структура

```
├── index.html   # главная
├── ron.html     # карьера
└── style.css    # стили
```
